🎯 기획안: PPT 템플릿 이미지 기반 레이아웃 리뉴얼 추천 시스템
📌 1. 프로젝트 개요
목적
기존 구식 PPT 슬라이드를 현대적인 템플릿으로 자동 리뉴얼하기 위한 시스템을 구축한다.
직관적인 "이미지 기반" 접근으로 콘텐츠와 무관하게 레이아웃 구조 중심의 추천을 수행한다.

🧱 2. 기능 구성
2.1 PPT 템플릿 전처리
사용자가 보유한 PPT 템플릿 폴더 전체를 이미지(.png) 로 변환

각 슬라이드를 비율 유지 + 640×640 정방형으로 리사이즈

여백은 검정색으로 패딩 처리하여 시각적 왜곡 방지

2.2 관심영역(ROI) 선택
리뉴얼 대상 PPT 슬라이드에서 특정 **영역(레이아웃 블록)**을 선택

관심영역을 “커널”로 정의하여 이후 유사영역 탐색에 사용

2.3 유사 템플릿 탐색
모든 템플릿 이미지에 대해 선택된 ROI와 유사한 영역 탐색

슬라이딩 윈도우 방식 적용

유사도 측정 알고리즘:

SSIM (구조적 유사도 지수)

템플릿 매칭 (cv2.matchTemplate)

(확장 시) CNN 기반 피처 추출 가능

2.4 유사 템플릿 추천
유사도 상위 3개 영역 추출

해당 슬라이드의 미리보기 이미지와 함께 사용자에게 표시

클릭 시 PPT로 적용하거나 레이아웃 참고용으로 활용

🧠 3. 기대 효과
레이아웃 중심의 PPT 리뉴얼 자동화

콘텐츠와 무관하게 디자인 구조에 기반한 추천 가능

기획자·디자이너의 반복 작업 감소

PPT 외 보고서·포스터·웹 템플릿 등에도 확장 가능
